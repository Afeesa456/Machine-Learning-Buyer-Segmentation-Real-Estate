# Machine Learning Based Buyer Segmentation and Investment Profiling

## Project Overview
This project applies K-Means clustering to segment real estate buyers based on demographic and investment characteristics.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit

## Features
- Interactive Filters
- KPI Cards
- Buyer Segmentation
- Geographic Analysis
- Loan Analysis
- Referral Analysis
- Business Insights
